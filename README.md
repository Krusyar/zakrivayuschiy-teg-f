# Закрывающий тег

Проектная работа по адаптивной вёрстке и анимациям.

## Описание
Проект посвящён рефлексии учебного пути во фронтенде.  
В работе реализованы:
- адаптивная вёрстка;
- карточки с изображениями и лейблами;
- анимированная иконка лайка;
- кнопки с эффектами наведения и фокуса;
- модальное окно на `dialog`;
- favicon и публикация на GitHub Pages.

## Технологии
- HTML
- CSS
- SVG
- JavaScript
